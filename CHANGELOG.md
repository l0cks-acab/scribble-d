# Changelog

## Scribble'd 0.1.0+26.1.2

**Minecraft 26.1.2**
- Ported to Minecraft 26.1.2 / NeoForge 26.1.2. Needs Java 25.
- Same features as 0.1.0: multi-block whiteboards up to 8x8, draw screen with 16 dyes + RGB picker + brush sizes + paint bucket, in-world markers and Board Eraser, undo, glow ink, boards keep their drawing when broken.
- The undo key now sits in its own "Scribble'd" controls category.

## Scribble'd 0.1.0

**First release (Minecraft 1.21.1)**
- Whiteboards that merge into one big board (up to 8x8 blocks), 64x64 pixels per block.
- Draw screen: 16 dye colours, eraser, RGB picker with hex input, brush sizes 1/2/3/5/8, paint bucket fill across the whole board, Undo, Clear.
- Markers and the Board Eraser draw straight on the board in the world; sneak for a fine tip.
- Undo with Z in the world or Ctrl+Z in the screen (last 30 strokes).
- Glow ink sac makes a board full-bright, ink sac turns it back. A broken board keeps its drawing on the item.
